NOVA STORE — قالب متجر إلكتروني عربي
======================================

التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح لمعاينة المتجر.
3) ارفع الملفات الثلاثة (index.html وstyle.css وscript.js) إلى نفس مجلد مشروع GitHub Pages.

تخصيص المتجر:
- افتح script.js.
- غيّر STORE_WHATSAPP إلى رقمك بصيغة دولية بدون + أو مسافات. مثال مصر: 2010xxxxxxx.
- عدّل مصفوفة products لتغيير أسماء المنتجات والأسعار والأقسام والرموز.
- عدّل SHIPPING_FEE وFREE_SHIPPING_FROM لتغيير الشحن.

مهم بخصوص الدفع:
هذا إصدار واجهة متجر يعمل في المتصفح: عرض منتجات، بحث وتصنيف، سلة، كميات، نموذج طلب، وتجهيز الطلب على واتساب. خيارات الدفع المعروضة هي الدفع عند الاستلام أو التحويل اليدوي إلى Vodafone Cash / InstaPay، ولا يجري الموقع خصم أموال أو التحقق تلقائيًا من التحويل.
لتفعيل دفع إلكتروني حقيقي بالبطاقات أو المحافظ، تحتاج حساب تاجر لدى بوابة دفع (مثل Paymob أو Fawry)، ومفاتيح API، وخادم Backend آمن لمعالجة الدفع والتحقق من Webhooks. لا تضع مفاتيح سرية داخل ملفات HTML أو JavaScript الموجودة في المتصفح.
المنتجات الحالية وأسعارها تجريبية ويجب استبدالها ببياناتك الفعلية قبل البيع.
